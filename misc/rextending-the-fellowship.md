# Path to Mordor: A Lord of the Rings Arcade Game

**Description:**
"Path to Mordor" is a low-code 2D endless runner built using MakeCode Arcade. The player controls Frodo Baggins as he navigates the dangerous path to Mount Doom. The objective is to survive as long as possible by dodging incoming Orcs while collecting Lembas bread for bonus points.
